# MowiShift Product Definition

**Version:** 1.0
**Status:** Draft
**Owner:** Yuliia Nosachova

---

# 1. Product Vision

## Mission

MowiShift is a modern workforce scheduling and shift management platform designed for the seafood processing and manufacturing industry. It helps administrators create efficient schedules while giving employees easy access to their work information, requests, and communication.

The primary goal is to simplify workforce planning, reduce scheduling errors, improve communication, and increase operational efficiency.

---

# 2. Target Users

## Administrator

The administrator is responsible for workforce planning and daily operations.

### Responsibilities

- Create and manage work schedules
- Assign employees to shifts
- Manage departments and workstations
- Record absences
- Monitor working hours
- Review workforce statistics
- Communicate with employees
- Generate reports

---

## Employee

Employees use the system to manage their daily work.

### Features

- View personal schedule
- Receive notifications
- Submit requests
- Exchange shifts
- Accept extra shifts
- View work history
- Track personal statistics

---

# 3. Product Goals

MowiShift aims to:

- Reduce the time required to create work schedules
- Minimize scheduling errors
- Simplify shift exchanges
- Improve communication between administrators and employees
- Provide real-time workforce visibility
- Increase productivity and operational efficiency

# 7. Product Principles

Every new feature should follow these principles:

1. Simple and intuitive.
2. Fast and efficient.
3. Reliable.
4. Responsive.
5. Accessible.
6. Secure.
7. Scalable.
8. Easy to maintain.

---

# 8. Success Metrics

The success of MowiShift will be measured by:

- Time required to create schedules
- Number of processed requests
- Number of completed shift exchanges
- Shift coverage rate
- Daily active users
- User engagement
- User satisfaction

---

# 9. Out of Scope (MVP)

The following features are not included in the first release:

- Payroll management
- Accounting
- Financial management
- Warehouse management
- Production management
- CRM functionality

These features may be implemented in future versions or through third-party integrations.

---

# 10. Long-Term Vision

MowiShift is designed as a scalable SaaS platform for workforce scheduling and employee management.

Although initially inspired by the needs of seafood processing companies, the platform is intended to support manufacturing, logistics, food production, and other industries that require efficient shift planning.

## Core Values

- Simplicity
- Performance
- Reliability
- Modern user experience
- Scalability
- Nordic UI Design System
- Long-term maintainability
